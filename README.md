🛗 Elevator Management & Analytics SystemAn advanced database architecture and tracking system designed for high-rise buildings, malls, and transit hubs. This system optimizes vertical transportation through Odd/Even floor logic and provides automated Maintenance triggers based on usage metrics.
🏗️ System Architecture1. Database Schema (ERD Relationships)The system is modeled with high normalization to ensure data integrity across building components.Building ➔ Elevator/Floor: A 1:N relationship defining the physical infrastructure.Elevator ➔ Ride: Captures real-time movement and payload data.Ride ➔ Tracking: Aggregates raw ride data into periodic analytics (Weekly, Monthly, Quarterly).Maintenance ➔ Elevator/Ride: Connects machine health to actual usage cycles.2. Core Entities & Data DictionaryBuilding & InfrastructureTableKey FieldDescriptionUsernoofreqTracks the number of requests made by a specific user.BuildingNoofFloorTotal floors (Supports INT for calculation).ElevatortypeLogic identifier: Even or Odd floor service.FloorfloorNoMapping of physical floor levels to the building ID.Tracking & OperationsTableKey FieldDescriptionRideRide_CountIncremental counter for individual trip sessions.Trackingperiodic_ride_countAggregated metrics for high-level reporting.TrackingstatusCurrent machine state: idle, moving, maintenance.MaintenanceUpcomingMDatePredicted service date based on Ride_id thresholds.💡 Technical LogicOdd/Even OptimizationTo reduce wait times and energy consumption in high-traffic environments, elevators are categorized via the type variable:Even Units: Optimized for floors $2, 4, 6, \dots, n$.Odd Units: Optimized for floors $1, 3, 5, \dots, n$.Performance AnalyticsThe system tracks two primary "Peak Performance" indicators:most_active_elevator: Identified by the highest Ride_Count in a rolling 24-hour window.most_visited_floor: Calculated by aggregating destination data from the Ride logs to identify building "Hotspots" (e.g., Food Courts or Lobbies).🛠️ Implementation DetailsSQL Schema ReferenceSQL-- Relationship Mapping for Eraser.io / SQL
